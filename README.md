# 播客剪辑台

一个纯本地的播客剪辑网页工具:把多段录音摆到同一条时间线上剪辑、混音,试听满意后导出 WAV。
无需后端、无需账号,音频不会上传任何服务器——所有解码、混音、导出都在浏览器内完成。

技术栈:TypeScript + React + Vite,音频处理基于 Web Audio API(导出混音为纯 TS 实现,与试听规则一致)。

## 启动

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

## 测试与构建

```bash
npm test           # vitest:时间计算 / 撤销重做 / WAV 编码 / 混音导出 / UI 冒烟
npm run build      # tsc 类型检查 + vite 产物构建
```

## 功能

- **素材**:导入多个本地音频文件(每个文件自动建轨);没有素材时点「演示工程」加载内置工程(人声 + 配乐两条不同音轨,片段有重叠,音频由算法本地生成)。
- **剪辑**:片段可拖动、两端裁剪、在播放头处分割(工具栏按钮分割所有命中片段,片段面板只分割选中片段)、删除(Delete 键)、复制到其他轨道;支持缩放(工具栏 ±)与横向滚动。剪辑不破坏原始素材,裁剪不能越过素材边界或负时间。
- **混音**:每轨音量 / 静音 / 独奏(有独奏时只出声独奏轨);每个片段可单独设置淡入淡出;同轨片段允许重叠,重叠部分声音叠加。
- **试听**:空格或按钮播放/暂停,暂停后接着播;点击刻度尺定位;在刻度尺上拖动框选一段时间,勾选「循环选区」循环试听;播放中调音量/静音/独奏立即生效;停止后不留残余声音。
- **撤销/重做**:Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z(或 Ctrl+Y),覆盖剪辑与混音参数;一次拖动算一次操作;撤销后再编辑会丢弃旧重做分支;音频素材不受撤销影响。
- **工程文件**:「保存工程」把全部音频素材(16-bit PCM)+ 编辑状态打包成单个 `.podproj` 文件;「打开工程」完整恢复。文件损坏或格式不支持会提示且不清空当前工程;有未保存修改时新建/打开/关闭页面都会提醒。
- **导出**:整个工程或选中范围 → 双声道 16-bit WAV,44.1kHz / 48kHz 可选,带进度条。导出与试听一致(裁剪、重叠、音量、静音独奏、淡入淡出),选区外的声音不会混入,空轨道不拖长时长,超幅钳制不爆音。

## 工程文件格式(.podproj)

```
8 字节  magic "PODPROJ1"
4 字节  JSON 长度 (LE)
N 字节  JSON { version, name, tracks, sources }
其余    每个素材的 16-bit PCM,按声道依次存放
```

## 目录结构

```
src/
  model/    类型、时间线操作(移动/裁剪/分割)、撤销重做历史
  audio/    WAV 编码、混音渲染、播放引擎、工程文件、演示工程、导出
  state/    React 状态(reducer + 事务式拖动提交)
  components/ 工具栏、走带、时间线、片段、轨道头、片段面板、导出对话框
  tests/    单元测试与 UI 冒烟测试
```
